# CHIP-8 Emulator

A CHIP-8 interpreter written from scratch in C, using SDL2 for graphics and input. Built as a
project to learn C: memory, pointers, bit manipulation, and working with a real library.

## Status

Work in progress. Currently modelling the machine state.

## Requirements

- GCC (C11)
- GNU Make
- SDL2 development libraries (`libsdl2-dev` on Ubuntu)
